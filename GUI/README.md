# Filter GUI

[项目介绍](../README.md) · [图文使用教程](../docs/tutorial.md)

macOS 26+ / Apple Silicon 原生应用，SwiftUI + AppKit + ImageIO，采用系统 Liquid Glass。使用原有 `nikonfilter.py` 整理引擎，命令行入口继续可用。

## 使用

打开 `~/Applications/Filter.app`。选择素材父目录，选择普通、RED 或自定义模式，可叠加旅行模式和演练模式。先预检查，再执行。操作记录可查看日志、撤销最近一次实际移动。

在「沉浸选片」浏览 JPEG / RAW：

- 左右方向键：上一张 / 下一张。
- 单击照片：点击位置的 1:1 原始像素 / 适应窗口；Retina 按真实像素计算。
- 双指缩放、滚动平移；Tab 隐藏侧栏；支持系统全屏。
- 左下角绿色「仅 JPEG」显示全部 JPEG，黄色「仅 RAW」直接解码显示全部 RAW，红色「JPEG+RAW」仅显示经过验证的配对 JPEG。删除 / 移入待删池分别处理 JPEG、RAW、或已配对的两者；选中项与预览条光色显示当前查看及删除范围。
- Delete：按当前模式移入 macOS 废纸篓。⌘Z 或撤回按钮恢复，重启后记录仍然可用。原路径已有文件时停止恢复，避免覆盖。清空废纸篓后无法恢复。
- I：打开 / 关闭右侧 Liquid Glass 照片信息栏，显示当前所查看文件的直方图、EXIF、JPEG/RAW 是否齐全、配对状态和验证依据。

## 配对验证

优先依据 `.nikonfilter_logs` 中的整理前父目录和文件名，将实际迁移后的 JPEG / RAW 对应起来，支持两者发生不同重名后缀的情况。没有日志时，优先匹配同目录唯一同名，再匹配所选目录树中唯一同名；可读取到 EXIF 日期时核对日期，冲突不配对。存在多个候选时标记歧义，禁止联动删除 RAW。

所选文件夹就是项目边界，递归读取其全部子目录；不会因为上级存在日志或同名 JPEG/RAW 目录就自动切换到上级。需要跨文件夹配对时，请明确选择它们的共同父目录。缺失 EXIF 时，文件名匹配属于命名依据，信息浮窗会说明验证依据。

整理记录随素材保存，最近目录保存在应用偏好中。删除撤回记录保存在 `~/Library/Application Support/Filter/trash-history.json`，包含废纸篓位置。外部移动/删除素材后使用刷新按钮重新检查。

## 构建与验证

```sh
bash GUI/build.sh             # build/Filter.app
bash GUI/build.sh --install   # 安装到 ~/Applications 并启动
python3 GUI/test_filter.py    # test 样本副本的端到端检查
```

构建需要 Swift 命令行工具和 macOS 26+ SDK。应用在当前 Mac 上调用 `/usr/bin/python3`（本机已经安装），无第三方 Python 依赖；分发到其他 Mac 需确保该解释器可用。当前构建为本机 ad-hoc 签名，未作商店分发或公证。

遵循 [Apple 的 Liquid Glass 采用指南](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)：玻璃用于浮动控制和信息层，照片保持清晰，使用系统玻璃实现及无障碍动态设置。

## 1.1：影子待删池与项目工作流

首页点击大号「+」或侧栏「+」选择素材目录。读取时显示转圈，完成后自动显示 JPEG、RAW、视频和各扩展名数量，底部可以直接确认整理。更改模式或旅行选项会自动更新整理预览。已整理项目显示整理摘要和选片入口；整理设置与预览始终可见，新增素材后会重新显示待整理状态。

侧栏保存影像项目：在「素材整理」打开项目会显示该项目的统计与整理状态；在「沉浸选片」打开会进入对应照片。左上角按钮可折叠为图标栏，Tab 仍可完全隐藏侧栏。项目记录保存在应用偏好，操作日志和待删恢复映射随素材保存。

| 操作 | 功能 |
| --- | --- |
| A / ← | 上一张 |
| D / → | 下一张 |
| W | 按绿/黄/红当前范围移入待删池，并立刻切下一张 |
| S / Delete | 按当前范围移入系统废纸篓，并立刻切下一张 |
| ⌘Z | 撤回最近一组废纸篓删除 |
| 单击 | 适应窗口 / 1:1 原始像素 |
| 1:1 下拖动 | 平移查看细节；拖动不会触发点击缩放 |
| I | EXIF、配对和所在池信息 |

待删池是正式分类文件夹的平行目录，增加大写 `D` 前缀。例如：

```text
项目/
  Jpg项目/20261101Jpg项目/DSC_0920.JPG
  Raw项目/20261101Raw项目/DSC_0920.NEF
  DJpg项目/20261101Jpg项目/DSC_0920.JPG
  DRaw项目/20261101Raw项目/DSC_0920.NEF
```

W 使用真实移动，保留文件字节和旅行子目录结构，不复制双份。未整理的混合目录会建立 `DJpg目录名` / `DRaw目录名`。正式整理与预检查会跳过 D 前缀待删目录。重名目标自动避让，原始对应路径写入项目 `.nikonfilter_logs/pool.json`，写入映射后才开始移动。

右上角「正式池 / 待删池」切换复核，当前池分别以绿色和橙色高亮，数量跟随查看范围。正式池按 W 移入待删池，待删池按 W 恢复当前照片在所选范围内的文件。两个池都可按 S 或 Delete 移入系统废纸篓，按 ⌘Z 撤回。原路径已有文件时会停止恢复。操作记录页仍可按恢复记录批量恢复。

可以在待删池存在时继续整理其他素材，照片对应关系会根据移动日志更新。待删池文件进入废纸篓后，可先按 ⌘Z 撤回，再按 W 恢复至正式池。手工建立的 D 目录没有恢复记录时，W 将文件移到对应的无 D 前缀目录。

图像采用解码缓存、相邻照片预读、Core Animation 图层平移；预览不再显示流光边框，拖动过程中不重新解码或读取 EXIF。原图缓存按内存容量在 320–768 MiB 内设置上限，最多保留三帧；排队的预读成为当前照片时会提升优先级。首次加载仍取决于文件大小和磁盘速度；已预读的照片直接复用解码结果。

```sh
bash GUI/build.sh
build/Filter.app/Contents/MacOS/Filter --self-test "$PWD/test"
python3 GUI/test_filter.py
build/Filter.app/Contents/MacOS/Filter --display-benchmark "$PWD/build/体验项目/DSC_0920.JPG"
```

测试程序在临时目录中复制样本，不改变当前 `test` 的正式池/待删池状态。显示性能测试会短暂打开一个窗口，进行 3 秒的真实显示回调与 1:1 平移测量。也可直接打开项目：`open -a ~/Applications/Filter.app --args --project /素材目录`。


## 1.1.1：目录边界与增量整理修复

- 选择哪个目录就读取哪个目录，任何深度都不自动跳到父目录；页面显示完整目录路径和输出范围。
- 正式池统计包含所选目录下全部深度的素材，待删池单列；不会把普通 `Drawings` 文件夹当待删池。
- 是否完成根据现有待整理素材判断。有历史日志但有新增文件时仍为待整理。自定义规则只处理一部分时不会把整个项目标记完成。
- 已分类目录中的正确位置文件保持原位；错放类型和更深层的新素材仍进入整理预览。
- 无法读取的子目录会报错，避免默默漏统计。
- 项目右键支持「删除项目（保留素材）」，只删除应用中的记录；照片、RAW、待删池、操作和恢复日志全部保留。可再次选择同一目录重新添加。

针对目录层级的独立回归：`python3 GUI/test_scan_scope.py`。

## 1.2：对焦点、系统主题与体积

- 移除了预览流光边框。绿/黄/红删除范围按钮保留，待删池图标改为向上箭头。
- 背景、文字、卡片和玻璃控件跟随 macOS 的浅色/深色外观，不覆盖系统偏好。
- `0`（含数字小键盘）按相机记录的对焦坐标，在该位置以真实 100% 像素显示。普通单击仍按点击位置放大。`、`、逗号键与 `\` 键恢复适应窗口，工具栏和「浏览」菜单也有入口。
- 当前支持 Nikon AFInfo2 0300/0301、0400/0401/0402 的明确坐标（覆盖样本 Z 8）。读取 EXIF 旋转/镜像方向，按 AF 参考画布缩放至当前 JPEG；JPEG 无可读坐标时尝试已配对 RAW。1.4 起，无可读坐标或参考比例不符时按中心 100% 兜底，界面明确标为「中心 100%」。RAW 回退要求显示比例相符；经裁切的衍生图可能不保留原相机坐标关系。
- 对焦点表示相机记录的 AF 区域位置，不保证画面一定合焦；相机明确记录未合焦时会提示。
- 项目行增加「素材数 · 项目体积」，项目列表标题旁可刷新所有项目，右键可刷新单个项目；刷新非当前项目不会切换正在浏览的目录。
- 整理页增加项目总大小、素材大小、待删池大小及 JPEG / RAW / 视频类别大小；该页刷新按钮会重新读取数量、大小、配对和整理状态。
- 大小按所选目录树中非隐藏、非符号链接文件的**逻辑字节数**统计；项目总大小包含待删池和普通附属文件，隐藏操作日志与 macOS `._` 文件不计。不是文件系统压缩/稀疏文件的已分配块数。W 移动不增加总大小，S 移入废纸篓后从项目中扣除；撤回与恢复后重新核对。
- 旧项目记录可以直接读取，尚未刷新大小时显示「体积待读取」。

图标保留原图的金属 Z 与深蓝底板主题，使用 `GUI/DrawIcon.swift` 的可编辑矢量路径重绘。构建时产生矢量 PDF 和 16–1024 px 的透明图标资源，方形底板位于 1024 画布的 100–924 区域，原始 `filter1.jpg` 保留。

对焦字段依据：[ExifTool Nikon AFInfo2 文档](https://exiftool.org/TagNames/Nikon.html)。样本及功能验证：原生 `--self-test`；精确大小验证：`python3 GUI/test_storage.py`。`--render-previews <目录>` 输出浅色、深色整理页预览，不改系统主题设置。

项目列表批量刷新为单目录设置读取超时；连接或访问阻塞时保留上次统计并提示错误，其他项目仍继续刷新。正常打开单个项目使用完整读取流程。

## 1.3：对焦点保持与悬浮预览条

- 按 `0` / 数字键盘 `0` 进入对焦点 100% 模式，之后用方向键、A/D、缩略图或 W/S 自动切换照片时，都按新照片自己的对焦坐标以 100% 显示。顶部对焦按钮会高亮。按 `、`、适应窗口按钮，或单击已放大的照片恢复适应窗口，即退出保持；普通点击放大仍在切图后回到适应窗口。
- 1.4 起，没有可用 AF 坐标的照片以画面中心显示真实 100%，保持意图继续保留，下一张有坐标的照片仍自动进入对焦点 100%。快速切换及读取期间手动适应窗口均有路径和请求令牌校验，旧回调不能覆盖当前照片。
- 下方 Liquid Glass 悬浮条展示前 3 张、当前及后 3 张。靠近首尾时保留中心位置，缺少的一侧留空。单击小图可以跳转；顶部预览条按钮、`T` 键或「浏览」菜单可切换，开关状态会保存。
- 切图时相邻小图平滑移入中心；W 使用向上飞出的小图快照，S / Delete 使用 70 块带原图纹理的粒子碎片消散。位移及粒子由 Core Animation 图层播放，不逐帧重新布局 SwiftUI 窗口。动画并行播放，文件操作与下一张预览不等待动画结束。关闭预览条时不产生这些视觉效果。
- 小图独立按最大 320 px 解码，使用 24 MiB 有界缓存及后台队列，不为预览条加载七张原尺寸照片。减少动态效果开启时改为短淡出，不播放飞出和碎片位移。

验证：`build/Filter.app/Contents/MacOS/Filter --self-test "$PWD/test"`。测试使用样本副本，包含实际 SwiftUI / AppKit 窗口中的对焦点保持、快速切图、适应窗口解除、缺失 AF 恢复、缩略图开关持久化及 W/S 事件；粒子逐像素渲染检查与真实窗口显示回调测量同时运行。

## 1.4：中心兜底、系统图标与界面精简

- `0` / 数字键盘 `0` / 字母 `O`：有可读 AF 坐标时按焦点 100%，否则立即按画面中心 100%。JPEG 缺失坐标但 RAW 有坐标时，后台读取后定位真实焦点；手动适应窗口会取消尚未返回的读取。中心兜底不会退出对焦点保持。判断依据是元数据中有没有可读坐标，不是根据画面的景深或清晰度猜测。
- 文件名下方及照片信息面板显示「适应窗口」「对焦点 100%」「中心 100%」或手动缩放比例。
- 原图缓存按物理内存 / 24 设置，限制在 320–768 MiB，最多三帧；当前帧复用并提升已排队的预读，避免重复解码。
- 移除侧栏底部标语、底部快捷键重复文本、品牌页脚和装饰性英文口号；浏览页隐藏常驻状态页脚，整理和记录页保留必要状态。快捷键仍可从菜单和按钮提示查看。
- 工具栏使用共享 GlassEffectContainer，浮动控制、EXIF 面板和预览条增加原生交互玻璃及细致边缘和阴影；缩略图的悬停抬升、边缘和透明度变化由 Core Animation 处理，不增加常驻逐帧任务。内容统计区域继续使用清晰的普通背景。
- `Info.plist` 指向版本化的 `Filter-1.4.icns`；运行时更新应用图标。安装会退出旧进程、覆盖应用、移除开发构建的系统登记，再登记正式安装路径，防止旧实例和旧登记继续使用过期资源。

安装时也可恢复指定项目与照片：

```sh
bash GUI/build.sh --install --project /素材目录 --photo /素材目录/Jpg素材目录/照片.JPG
```

## 1.5：项目在线状态与明亮色板

- 每个项目文件夹右下角的小圆点现在表示**项目目录是否可访问**，与是否整理完成无关：绿色 `#1dcd3a` 在线，黄色 `#ffbb10` 离线。检查中也使用柔和黄色，悬停文字会区分状态；项目按钮的无障碍描述同步显示在线或离线。
- 启动、应用重新激活、系统唤醒、磁盘挂载 / 卸载 / 重命名时更新状态，并每约 8 秒在后台补查目录是否仍存在。只检查目录，不扫描照片；同一路径的检查合并，状态没变化时不触发界面重绘。
- 拔盘后旧检查结果不能把项目误标回在线。接回磁盘且原项目路径可访问时自动恢复绿色；目录被移走或无法访问也显示离线。离线时保留原有素材数量和体积，重新连接后可用刷新重新统计。
- 离线项目不能发起 W/S 文件操作；点击离线项目会说明连接状态并保留当前浏览画面。
- 全界面使用 `GUI/Appearance.swift` 中的九组指定色板：亮蓝为主，薄荷青与浅粉用于轻量底色和玻璃边缘，JPEG / RAW / 视频 / 配对卡片分别以绿、紫、橙、青区分。三种删除范围继续使用绿、黄、红。
- 在线绿灯带轻柔呼吸光晕，离线黄灯保持稳定。呼吸由 Core Animation 播放，不逐帧更新 SwiftUI；开启系统“减少动态效果”后停止呼吸。主照片本身不增加变色或呼吸效果。
- 浅深色模式分别选择色板中的可读文字色，基础背景对比度检查达到 4.5:1；原有原生玻璃与悬停反馈保留。

## 1.6：中性工具栏、补充 EXIF 与项目置顶

- 选片顶部工具栏使用黑 / 白中性图标，照片池和工具分别组合为胶囊玻璃条；图标按钮统一为 32 pt 圆形命中区域，灰色底衬表示已开启。工具和次级操作不再继承蓝色强调色，主要操作仍保留必要强调。文字按钮使用胶囊曲线，侧栏新增按钮使用圆形。
- 照片信息新增曝光补偿、测光模式和闪光灯。曝光补偿显示带正负号的 EV；测光模式按标准 EXIF 枚举命名；闪光灯按“是否实际触发”的位标志判断，自动模式不等于已闪光。缺失字段显示「未记录」，不将缺失当成 0 EV 或未闪光。
- 普通项目使用固定添加顺序，点击、刷新只更新项目内容，不改变排列；新项目追加到列表末尾。旧版本没有保存最初添加时间，升级时保留已有列表顺序作为基准。
- 右键可「置顶项目 / 取消置顶」。新置顶项排在最上面，支持多个置顶；取消后回到普通项目原有的位置。置顶独立持久化，删除项目同步清理，重新添加不会恢复旧置顶。
- 只有置顶项目显示渐变背景和图钉。普通选中项目只改变文件夹图标颜色，在线 / 离线灯继续独立表示目录状态。整行均可点击和右键。

## 1.7.1：统一工作区、RGBW 直方图与拖动导航

- 照片、右侧信息栏、底部玻璃预览条采用独立布局区域，避免互相覆盖；信息栏可关闭并滚动查看完整 EXIF。内外界面共同跟随系统主题，使用中性底色和紧凑工具。
- 照片信息顶部新增实际 JPEG 的 sRGB 红、绿、蓝及白色亮度直方图。默认对数纵轴展开低频色阶，点击「对数 / 线性」切换并记住选择；横轴始终是 0–255。附黑 / 白端像素比例。
- 预览条可左右拖动、触控板横向滚动或普通滚轮导航。保留前后三张、点击选图、焦点放大保持与 W / S 动画；快速导航自动取消过时的排队解码。
- 收起侧栏的所有图标采用同宽格子、统一中心线；项目置顶、在线状态及右键菜单继续保留。

## 1.7.2：预览条状态光

- 大图改为中性细边；删除范围的颜色集中到预览条和当前缩略图。仅 JPEG 为绿、仅 RAW 为黄、JPEG + RAW 为红。
- 预览条使用轻透染色和柔光；当前缩略图具有彩色光晕与玻璃反光边缘。切换范围时平滑变色，切图时光晕跟随当前照片，其他缩略图保持中性。
- 减少动态效果时保留静态状态光。删除范围会记住，重启后保持同一工作模式。

## 1.7.3：收敛缩略图光效

- 去掉当前照片的双层彩色硬边，改为同一轮廓上的 0.6 pt 细反光与柔和外晕，降低饱和边缘和呼吸幅度。
- 照片、反光和光晕共同缩放；调整窗口和拖动预览条时保持圆角对齐。

## 1.8：三种查看范围与原生 RAW 显影

- 仅 JPEG / 仅 RAW / JPEG+RAW 同时决定查看清单和处理范围。RAW 清单独立收录有配对、未配对和配对歧义的全部 RAW；配对范围仅显示已验证的 JPEG。
- RAW 大图使用系统 Core Image `CIRAWFilter` 解码原始影像，以原生像素尺寸显示；不借用配对 JPEG。缩略图也使用 RAW 解码。100% 放大、焦点保持 / 中心兜底、拖动预览条、W / S / 撤回和三色光效均随当前范围工作。
- RAW 直方图标记「RAW 显影 · sRGB」，反映显示画面而非未处理的传感器数值。系统不支持的相机编码或损坏文件会明确提示解码失败，不显示另一张照片。
- 正式池和待删池分别记录实际 JPEG / RAW。只移动或删除一侧时，另一侧仍可独立查看；恢复后重新验证配对。空范围保留切换按钮。

## 1.9

- 影像项目旁的排序菜单支持添加顺序、自定义日期与时间、项目大小和名称，均可正序或倒序。右键项目可设置或清除日期与时间。置顶项目继续保持在列表最上方。
- 按 **B** 或顶部叠片按钮识别并折叠连拍，再按一次展开。支持带有连拍组元数据的 Nikon Z8/Z9 JPEG 和 NEF，连拍标记显示该范围内的帧数。W/S 作用于当前照片，展开后可逐帧操作。
- 预览条下方的快速定位轨覆盖整个当前列表。拖动时可看见目标文件名及序号，松手后加载目标。缩略图仍可拖动和滚动，用于微调相邻照片。

## 1.9.1

- 正式池和待删池使用等宽、等高的分段按钮，计数右对齐，切换时分别以绿色和橙色高亮。
- 进入选片后自动识别连拍。缩略图角标在折叠时显示组内总张数（如 `×3`），展开时显示组内位置（如 `2/3`）。按 **B** 或点击叠片按钮切换。
- 按 **F** 或点击顶部准星开关绿色对焦框。设置会保存。绿框跟随照片缩放与平移，只在可定位的相机对焦记录上显示。
- 照片信息显示有记录的对焦距离、对焦模式、区域模式和合焦结果。距离优先读取 Nikon Z 镜头数据，兼容标准 EXIF SubjectDistance，JPEG 缺失时也会检查已配对的 RAW。镜头报告的距离是估算值。

## 1.9.2

- 「文件与配对」分别显示 JPEG 和 RAW 的文件体积。将指针停在体积行上可查看精确字节数。缺少其中一种文件时显示「无文件」。

## 1.9.3

- 点击预览条缩略图的连拍角标，可以展开或折叠当前组。顶部叠片按钮和 **B** 统一切换全部连拍组。
- 工具栏依次排列对焦点放大、缩小至适应窗口和绿色对焦框开关。
- 「拍摄信息」显示 Nikon 文件中记录的色彩预设名及有区别的基础预设。当前文件没有该字段时，尝试读取已配对的文件。

## 1.9.4

- 直方图背景、网格、RGB 和亮度曲线随深浅色模式调整。
